print打印接口

产品支持情况​

  • Ascend 950PR/Ascend 950DT：支持
  • Atlas A3训练系列产品/Atlas A3推理系列产品：不支持
  • Atlas A2训练系列产品/Atlas A2推理系列产品：不支持
  • Atlas 200I/500 A2推理产品：不支持
  • Atlas推理系列产品AI Core：不支持
  • Atlas推理系列产品Vector Core：不支持
  • Atlas训练系列产品：不支持

功能说明​

头文件路径为：tensor_api/tensor.h。

Tensor API提供三个调试打印接口：

  • print：打印格式化字符串、标量、Tuple、Layout或Tensor描述信息。
  • print_layout：以二维表格形式打印Layout的逻辑坐标到物理索引的映射。
  • print_tensor：按照Tensor的逻辑坐标顺序打印元素数据，并可选择是否打印Tensor描述信息。

接口用于算子调试，不建议在正式性能测试或性能敏感路径中调用。打印数据会写入设备侧调试输出，多个核同时打印时输出顺序可能交错。

函数原型​

print​

C++
__aicore__ inline void print(__gm__ const char* fmt);

template <typename Arg0, typename... Args>
__aicore__ inline void print(__gm__ const char* fmt, Arg0&& arg0, Args&&... args);

template <typename Value, typename Std::enable_if_t<!detail::is_print_string_v<Value>, int> = 0>
__aicore__ inline void print(const Value& value);

print_layout​

C++
template <typename Layout>
__aicore__ inline void print_layout(const Layout& layout);

print_tensor​

C++
template <typename Tensor>
__aicore__ inline void print_tensor(const Tensor& tensor, bool print_type = true);

参数说明​

表1 print格式化接口参数说明

参数名输入/输出描述
fmt输入格式控制字符串。支持普通字符和%d、%lld、%f、%u、%s、%p等转换说明，转换说明的数量和类型必须与后续参数匹配。
arg0输入第一个格式化参数。
args...输入其余格式化参数。
value输入待打印的标量、Tuple、Layout或Tensor对象。

表2 print_layout参数说明

参数名输入/输出描述
layout输入待打印的Layout对象。其Shape必须在顶层包含两个元素；每个顶层元素可以是整数或嵌套Shape结构。

表3 print_tensor参数说明

参数名输入/输出描述
tensor输入待打印的Tensor对象。其Layout的Shape必须在顶层包含1到4个元素；每个顶层元素可以是整数或嵌套Shape结构。
print_type输入是否打印Tensor的指针位宽、地址和Layout描述。默认值为true；设置为false时只打印元素数据。

返回值说明​

无

约束说明​

  • 只有开启调试打印时才会产生输出。定义ASCENDC_DUMP=0时，三个接口均不输出数据。

  • print_layout只支持Shape在顶层包含两个元素的Layout。顶层元素可以是整数或嵌套Shape结构；顶层元素数量不为两个时会触发编译期校验。

  • print_tensor只支持Shape在顶层包含1到4个元素的Tensor。顶层元素可以是整数或嵌套Shape结构。顶层元素数量超出范围时会触发编译期校验。元素按逻辑坐标顺序访问，实际物理地址由Tensor的Layout决定；ND、NZ等Layout的内部对齐区域不会作为额外逻辑元素打印。

  • print_tensor支持打印的Tensor存储位置如下：

    存储位置是否支持
    location::gm支持
    location::ub支持
    location::l1支持
    location::l0c支持
    location::bias支持
    location::l0a不支持
    location::l0b不支持
    location::l0scalea不支持
    location::l0scaleb不支持
    location::fixbuf不支持
    location::ssbuf不支持

  • 打印功能会增加算子运行时间和调试输出量。打印Tensor前应控制Tensor的逻辑元素数量。多个核或多个线程同时打印时，日志可能交错或受输出缓存大小限制。

输出格式​

print输出​

print对Tuple保留嵌套结构，元素之间使用逗号和空格分隔；对Layout输出shape和stride；对Tensor输出指针位宽、地址和Layout描述，不输出Tensor元素。

支持直接打印的常用值类型如下：

值类型输出形式
int8_t、int16_t、int32_t、int64_t十进制有符号整数。
uint8_t、uint16_t、uint32_t、uint64_t十进制无符号整数。
float、half、bfloat16_t及其他浮点类型十进制浮点数。
Tuple按原有嵌套关系使用圆括号输出。
Layout输出layout(shape=..., stride=...)描述。
Tensor输出ptr[位宽](地址) o layout(...)描述。

字符串通过第一个参数fmt传入；需要输出字符串参数时，在fmt中使用%s并传入对应的字符串参数，例如print((__gm__ const char*)"name=%s\n", name)。

Tensor描述的格式为：

Text
ptr[<element_bits>b](<address>) o layout(shape=<shape>, stride=<stride>)

其中<element_bits>为元素位宽，例如普通float为32，4-bit数据类型为4。o用于分隔Tensor指针信息和Layout信息。

print_layout输出​

print_layout先输出Layout描述，再输出二维逻辑坐标到物理索引的表格。表格的行、列对应Layout的Shape顶层两个元素；每个元素可以是整数或嵌套Shape结构。单元格中的数值为调用layout(coord)得到的线性索引。

print_tensor输出​

当print_type为true时，先输出Tensor描述和冒号，再按逻辑坐标打印元素。不同维度的Tensor使用以下分隔方式：

  • 1维：每行一个元素。
  • 2维：每行一个逻辑行。
  • 3维：不同的第三维平面之间使用-分隔。
  • 4维：不同的第四维切片之间使用=分隔，第三维平面之间使用-分隔。

__aicore__ inline void print_scalar_and_tuple_example()

打印嵌套Shape的Tensor​

print_tensor会保留Shape和Stride的嵌套关系，并按照展开后的逻辑坐标顺序打印元素。以下示例分别展示两层嵌套和三层嵌套的Shape：

C++
#include "tensor_api/tensor.h"

using namespace asc::te;

__aicore__ inline void print_nested_tensor_example(__gm__ int32_t* data)
{
    auto shape_2d_nested = make_shape(make_shape(2, 2), make_shape(2, 2));
    auto stride_2d_nested = make_stride(make_stride(4, 8), make_stride(1, 2));
    auto tensor_2d_nested = make_tensor(
        make_mem_ptr<location::gm>(data), make_layout(shape_2d_nested, stride_2d_nested));
    print_tensor(tensor_2d_nested);

    auto shape_3d_nested = make_shape(2, make_shape(make_shape(2, 2), make_shape(2, 2)));
    auto stride_3d_nested = make_stride(16, make_stride(make_stride(1, 2), make_stride(4, 8)));
    auto tensor_3d_nested = make_tensor(
        make_mem_ptr<location::gm>(data), make_layout(shape_3d_nested, stride_3d_nested));
    print_tensor(tensor_3d_nested);
}

调用方应在调用print_nested_tensor_example前准备至少覆盖示例Layout访问范围的GM数据。对应的Tensor描述和元素排布如下（地址因运行环境而异）：
