Tensor API列表

基础数据结构​

表1 基础数据结构接口列表

类型或接口名功能描述
layout使用Shape和Stride描述数据的逻辑形状及其内存布局。
Shape描述Tensor各维度的逻辑形状，支持普通整数和嵌套元组形式。
Stride描述Tensor各维度相邻元素在内存中的地址步长，支持普通整数和嵌套元组形式。
Coord描述Tensor在各维度上的逻辑坐标。
global_tensor和local_tensor分别描述Global Memory和片上Local Memory中的Tensor对象。
Pointer描述Tensor的访问地址及其对应的存储位置。
make_layout根据Shape和Stride构造普通Layout。
make_pattern_layout根据Layout Pattern、Shape和Stride构造带有排布类型信息的Layout。
make_frame_layout根据卷积特征图或矩阵分形的Layout Pattern和形状参数构造Layout。
make_shape构造Shape对象。
make_stride构造Stride对象。
make_coord构造Coord对象。
make_mem_ptr根据指针和存储位置构造Tensor API内存指针对象。
make_tensor将内存指针和Layout绑定，构造global_tensor或local_tensor。
slice根据起始坐标和Shape或Layout描述创建原Tensor的子Tensor。

Layout操作​

表2 Layout操作接口列表

接口名功能描述
capacity获取Layout或指定子维度对应的实际内存容量。
coshape在编译期获取Layout指定子维度的Shape结构。
cosize在编译期获取Layout指定子维度的容量或元素数量。
crd2idx将多维坐标按照Layout转换为线性内存索引。
get获取元组中的指定元素，支持单个或多个编译期索引。
get_shape获取Layout的Shape或指定子维度的Shape。
get_stride获取Layout的Stride或指定子维度的Stride。
rank获取Layout的层级或维度信息。
select按指定索引从Layout的Shape和Stride中选择子结构。
size获取Layout的逻辑元素数量。
squeeze删除Shape顶层结构中指定的大小为1的维度。

数据搬运​

表4 数据搬运通路和接口列表

数据通路或接口名功能描述
Global Memory到Unified Buffer使用copy将Global Memory中的数据搬运到Unified Buffer，支持坐标区域搬运。
Unified Buffer到Global Memory使用copy将Unified Buffer中的数据搬运到Global Memory，支持坐标区域搬运。
Global Memory到L1 Buffer使用copy将Global Memory中的数据搬运到L1 Buffer，并支持多种矩阵格式转换和Batch搬运。
Unified Buffer到L1 Buffer使用copy将Unified Buffer中的数据搬运到L1 Buffer。
L1 Buffer到Unified Buffer使用copy将L1 Buffer中的数据搬运到Unified Buffer。
L1 Buffer到L0A Buffer使用copy将L1 Buffer中的左矩阵数据搬运到L0A Buffer，支持矩阵格式转换和卷积特征图搬运。
L1 Buffer到L0B Buffer使用copy将L1 Buffer中的右矩阵数据搬运到L0B Buffer，支持矩阵格式转换和Batch搬运。
L1 Buffer到L0ScaleA Buffer使用copy将L1 Buffer中的ScaleA数据搬运到L0ScaleA Buffer。
L1 Buffer到L0ScaleB Buffer使用copy将L1 Buffer中的ScaleB数据搬运到L0ScaleB Buffer。
L1 Buffer到BiasTable Buffer使用copy将L1 Buffer中的Bias数据搬运到BiasTable Buffer。
L1 Buffer到Fixpipe Buffer使用copy将L1 Buffer中的量化参数搬运到Fixpipe Buffer。
L0C Buffer到Global Memory使用copy将L0C Buffer中的矩阵结果搬运到Global Memory，支持格式转换和量化输出。
L0C Buffer到Unified Buffer使用copy将L0C Buffer中的矩阵结果搬运到Unified Buffer，支持格式转换和量化输出。
L0C Buffer到L1 Buffer使用copy将L0C Buffer中的矩阵结果搬运到L1 Buffer。
Unified Buffer内部搬运使用copy完成Unified Buffer内部Tensor之间的数据搬运。

HF32介绍矩阵计算中的HF32精度模式。

矩阵计算搬入总体说明说明矩阵数据从Global Memory或L1 Buffer搬入各级矩阵计算Buffer的通路。
矩阵计算搬出总体说明说明矩阵结果从L0C Buffer搬出到Global Memory、Unified Buffer或L1 Buffer的通路。

随路量化介绍矩阵结果搬出过程中的随路量化能力。
随路ReLU介绍矩阵结果搬出过程中的随路ReLU能力。
F32 Channel Split介绍F32结果搬出时的通道拆分能力。
Int8 Channel Merge介绍Int8结果搬出时的通道合并能力。
Batch搬运介绍矩阵结果的多Batch搬出能力。
L0C到Unified Buffer双目标模式介绍L0C到Unified Buffer的双目标搬出模式。

矢量计算接口​

表6 矢量计算接口列表

接口或类型名功能描述
reg_tensor封装矢量数据寄存器及其掩码寄存器，用于寄存器数据计算。
reg_pair保存两个元素类型相同的reg_tensor，用于具有双结果的寄存器接口。
all_mask创建与指定元素类型位宽匹配的全有效Mask寄存器。
make_mask根据Mask模式和数据元素宽度创建Mask寄存器。
none_mask创建与指定元素类型位宽匹配的全无效Mask寄存器。
update_mask根据剩余待处理元素数生成有效位Mask，并更新剩余元素数量。
deinterleave（掩码寄存器解交织）将两个Mask寄存器按指定元素宽度解交织，返回偶数组和奇数组结果。
load将Unified Buffer中的数据搬入reg_tensor，支持多种数据排列方式。
load_broadcast从Unified Buffer搬入数据，并按指定模式广播到reg_tensor。
store将reg_tensor中的数据搬出到Unified Buffer，支持多种数据排列方式。
cast转换寄存器数据类型，支持配置数据排布、舍入和饱和模式。
trunc将Mask选中的浮点元素向零取整，并保留原数据类型。
log对源操作数中的有效元素逐元素计算自然对数。
max对两个源操作数逐元素计算最大值。
operator+对两个源操作数逐元素执行加法计算。
operator-对两个源操作数逐元素执行减法计算。
operator*对两个源操作数逐元素执行乘法计算。
or对两个源操作数逐元素执行按位或计算。
选择与比较根据mask的比特位值，从源操作数src0、src1中选择元素，得到目的操作数。
select根据条件Mask从两个源寄存器中逐元素选择数据。
数据填充根据mask将源操作数src的最低位元素或者一个scalar操作数填充到目的操作数。
fill将标量或源寄存器最低位元素广播并填充到目的寄存器。
数据重排给定源操作数src0和src1，将src0和src1中的元素解交织存入结果操作数。
deinterleave（数据寄存器解交织）将两个源寄存器中的元素解交织到两个结果寄存器。
