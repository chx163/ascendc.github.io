优化手段解析与实施​

优化策略1：标量→向量指令​

原理解析：标量运算每次只能处理1个数据元素，需要逐元素循环；向量指令（如AscendC::Add）单次可处理多个数据元素，利用向量单元的并行计算能力，可获得百倍以上性能提升。

代码改造点：将for循环配合GetValue/SetValue的标量运算替换为向量API：

C++
// 标量方式（Case 0）
for (uint32_t i = 0; i < curLen; i++) {
    float xVal = (float)xLocal.GetValue(i);
    float yVal = (float)yLocal.GetValue(i);
    zLocal.SetValue(i, (half)(xVal + yVal));
}

// 向量方式（Case 1）
AscendC::Add(zLocal, xLocal, yLocal, curLen);

性能提升：端到端耗时从1239689.1μs降至6909.6μs，提升99.4%。

优化策略2：多核均匀切分 + 大块搬运​

原理解析：

  • 多核并行：将数据均匀切分到多个AIV Core，实现并行计算。使用均匀切分策略（余数分配到前几个核），确保负载均衡。
  • 大块搬运：在Unified Buffer（UB）空间允许范围内增大dataCopyLen，减少搬运次数，摊薄启动开销，更好地利用内存带宽。

代码改造点：

C++
// 均匀切分：计算每个核处理的行数
uint32_t baseCoreM = totalM / splitM;
uint32_t remainderM = totalM % splitM;
if (blockIdxM < remainderM) {
    actualCoreM = baseCoreM + 1;  // 均匀分配余数
}

// 增大搬运粒度：dataCopyLen从4096提升至16384（Case 2→Case 3）

性能提升：Case 2→Case 3，端到端耗时从306.58μs降至268.5μs，减少12.5%。

优化策略3：双缓冲流水线并行​

原理解析：采用Ping-Pong双缓冲技术，Ping缓冲区进行计算时，Pong缓冲区进行数据搬运，交替执行实现计算与搬运的流水线并行。

代码改造点：

性能提升：Case 3→Case 4，端到端耗时从268.5μs降至264.02μs，减少1.7%。双缓冲的收益有限，说明瓶颈在搬运速度本身。
