废弃接口

基础API​

  • WriteGmByPassDCache(ISASI)接口

    此接口后续版本会废弃，请使用WriteGmBypassDCache(ISASI)接口。

  • ReadGmByPassDCache(ISASI)接口

    此接口后续版本会废弃，请使用ReadGmBypassDCache(ISASI)接口。

C API​

原子操作​

  • asc_set_store_atomic_config_v2接口

    此接口后续版本会废弃，请使用asc_atomic_add接口。

  • asc_get_store_atomic_config接口（仅Ascend 950PR/Ascend 950DT）

    Ascend 950PR/Ascend 950DT上该接口已废弃，请使用asc_atomic_add接口。

  • asc_set_atomic_none接口

    此接口后续版本会废弃，请使用asc_disable_dma_atomic接口。

  • asc_set_atomic_add_int接口

    此接口后续版本会废弃，请使用asc_set_atomic_add_int32接口。

  • asc_set_atomic_max_int接口

    此接口后续版本会废弃，请使用asc_set_atomic_max_int32接口。

  • asc_set_atomic_min_int接口

    此接口后续版本会废弃，请使用asc_set_atomic_min_int32接口。

系统变量​

  • asc_get_block_idx接口

    此接口后续版本会废弃，请使用内置变量block_idx结合asc_get_sub_block_num和asc_get_sub_block_id接口计算逻辑核索引。

  • asc_get_block_num接口

    此接口后续版本会废弃，请使用内置变量block_num。

特殊寄存器访问​

  • asc_get_ar_spr接口

    此接口后续版本会废弃，请使用asc_get_squeeze_status接口。

    asc_or的浮点类型重载已废弃，请按位宽选择对应整数重载替代，详情请参见asc_or。
