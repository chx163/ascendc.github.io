高阶API迁移指导

Ascend C高阶API基本兼容NPU架构版本3510与NPU架构版本2201，部分API进行了扩展。当前3510架构不支持卷积计算类高阶API。

表5 量化操作

兼容说明

兼容2201架构。

扩展支持PRE_TOKEN量化、PRE_GROUP量化。

兼容2201架构。

AscendAntiQuant

兼容2201架构。

扩展支持PRE_TOKEN量化、PRE_GROUP量化。
