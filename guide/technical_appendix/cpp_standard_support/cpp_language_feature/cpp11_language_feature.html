C++11语言特性

本文介绍C++11语言特性在Ascend C Device侧的支持情况。下表列出C++11核心语言特性在Device侧的支持情况。

表1 C++11核心语言特性列表

C++11特性C++11 Proposal是否支持说明
*this的右值引用（Rvalue references for *this）N2439是支持func() &、func() &&、func() const &引用限定成员函数重载。
右值初始化类对象N1610是工厂函数返回右值时移动构造或返回值优化均生效。
变参模板N2242是支持参数包、sizeof...、包展开进数组初始化、函数实参、基类列表，递归继承展开。
静态断言N1720是支持命名空间级与函数内static_assert，可在模板中使用。
auto类型变量N1984是支持从初始化表达式、lambda表达式推导类型。注意Host侧auto dev = nullptr;声明的设备指针经aclrtMalloc传入核函数时Device地址不生效，设备指针应以显式指针类型声明。
多声明符autoN1737是一条语句声明多个auto变量，要求各声明符推导类型一致，不一致时编译报错。
Lambda表达式N2927是SIMD与SIMT混合编程场景需显式标记函数属性，详见Lambda表达式。
表达式的声明类型（Declared type of an expression，decltype）N2343是值类别语义与标准一致：具名实体推导声明类型，表达式按左值、右值推导引用。
右尖括号N1757是嵌套模板关闭符>>无需空格分隔。
别名模板N2258是支持template <typename T> using Alias = ...及元函数级联。
空指针常量（Null pointer constant，nullptr）N2431是支持nullptr初始化、比较与函数重载决议。
强类型枚举N2347是支持enum class及底层类型指定。
对齐支持N2341是支持alignas、alignof，可作用于类、全局与局部变量。
条件支持行为N1627是__int128扩展整型在Device侧可用。
委托构造函数N1986是支持构造函数委托链。
显式转换运算符N2437是支持explicit operator T。
新字符类型N2249是支持char16_t、char32_t作为算术类型参与运算。
字面量中的通用字符名N2170是支持UCN的UTF-8落地形式。
标准布局类型N2342是std::is_standard_layout判定与标准一致，<type_traits>可在Device侧使用。
defaulted函数N2346是构造、拷贝、移动、赋值、析构均支持= default。
deleted函数N2346是支持= delete，可构造move-only类型。
扩展friend声明N1791是支持模板友元不写<>的扩展形式。
扩展sizeofN2253、DR850是支持类成员sizeof且无需实例，以及sizeof...参数包。
定义移动特殊成员函数N3053是支持移动构造与移动赋值的定义、使用。

C99特性C++11 Proposal支持情况说明
__func__预定义标识符N2340是函数内隐式静态字符串数组可用。
C99预处理器N1653是支持可变参数宏__VA_ARGS__、记号粘贴##、字符串化#。GNU扩展##__VA_ARGS__空参吞并在可变参数为空时不可用，需以函数重载等方式替代。
