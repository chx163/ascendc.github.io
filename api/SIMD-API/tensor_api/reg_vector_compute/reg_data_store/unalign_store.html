功能说明​

头文件路径为："tensor_api/experimental/arch/vector/reg_data_store.h"，命名空间为asc::te::experimental。

unalign_store用于将reg_tensor中的数据连续搬出到非32字节对齐的Unified Buffer（UB）地址。对象内部维护一个非对齐搬出寄存器，提供以下两个操作：

  • store：将源寄存器前count个元素连续搬出。已形成的32字节对齐主块写入UB，非对齐尾块暂存到对象内部的非对齐寄存器中，供下一次连续搬出拼接。
  • flush：将非对齐寄存器中暂存的尾块写入UB。一次连续搬出序列结束后必须调用该接口完成收尾。

store使用src.reg，忽略src.mask。有效搬出元素数由count指定，不能使用mask替代count。本接口不会自动推进目的Tensor或坐标，调用者须根据累计搬出元素数指定下一次连续写入地址。

函数原型​

C++
struct unalign_store {
    __simd_callee__ unalign_store() = default;

    template <typename Tensor, typename RegDataType>
    __simd_callee__ inline void store(
        Tensor dst_tile, const reg_tensor<RegDataType>& src, uint32_t count);

    template <typename Tensor, typename Coord, typename RegDataType>
    __simd_callee__ inline void store(
        Tensor dst_tile, const Coord& coord,
        const reg_tensor<RegDataType>& src, uint32_t count);

    template <typename Tensor>
    __simd_callee__ inline void flush(Tensor dst_base, int32_t coord);
};

Coordstore的目的Tensor坐标类型，由函数实参自动推导。

表2 参数说明

参数名输入/输出描述
dst_tile输出本次搬出的目的Tensor。不传入坐标时，写入地址为dst_tile.engine().begin().get()。Tensor视图按值传入，不会修改调用者的视图，但会写入其指向的UB。
coord（store）输入本次搬出起始元素在dst_tile逻辑布局中的坐标，实际写入地址为(dst_tile.data() + dst_tile.layout()(coord)).get()。
src输入源reg_tensor，reg必须初始化，mask不参与搬出。
count输入本次搬出的元素个数，类型为uint32_t，不超过单个矢量寄存器可容纳的元素个数。
dst_base输出收尾使用的目的Tensor，其起始地址为本次连续搬出序列第一次store的实际写入地址。
coord（flush）输入类型为int32_t，传给底层收尾接口的元素偏移量，应为本次连续搬出序列各次count之和。它不是make_coord生成的逻辑坐标，也不是字节偏移。

flush使用的收尾地址由dst_base.engine().begin().get()和元素偏移coord确定。若第一次store指定了非零坐标，应将该坐标对应的Tensor视图作为dst_base，不能直接用未偏移的原Tensor配合本序列元素总数进行收尾。

返回值说明​

store和flush均无返回值。

约束说明​

  • 目的地址无需32字节对齐，但必须满足元素类型的对齐要求，实际写入范围不能超出有效UB空间。
  • 同一连续搬出序列必须复用同一个unalign_store对象，所有目的Tensor的元素类型必须一致。
  • 相邻两次store的实际写入地址必须连续，即下一次起始地址为上一次起始地址加已搬出数据长度。地址不连续时，应先对当前序列调用flush，再开始新的搬出序列。
  • 每个序列的全部store完成后，使用首次写入地址对应的dst_base以及累计搬出元素数调用一次flush。不能遗漏收尾，也不能在尚未进行store时调用flush。
  • count不得超过一个寄存器容量；例如uint8_t为VL / sizeof(uint8_t)个元素，float为VL / sizeof(float)个元素。
  • store的坐标维数必须与Tensor布局匹配，坐标不能越界；flush的元素偏移及最终地址必须在合法范围内。

调用示例​

以下示例连续复制uint8_t数据，最后一段通过count控制有效搬出数量。源、目的Tensor均为一维UB Tensor，起始地址可非32字节对齐；total_elements大于0且不超过int32_t上限。源UB空间必须为最后一次完整VL读取及前置缓存预留合法空间，目的UB空间必须覆盖全部写入数据。

C++
#include "tensor_api/tensor.h"
#include "tensor_api/experimental/vector_compute.h"

template <typename SrcTensor, typename DstTensor>
__simd_vf__ inline void CopyUnaligned(
    SrcTensor src, DstTensor dst, uint32_t total_elements)
{
    constexpr uint32_t elements_per_register = asc_get_vf_len() / sizeof(uint8_t);
    asc::te::experimental::unalign_load loader;
    asc::te::experimental::unalign_store storer;
    loader.prepare(src);
    for (uint32_t offset = 0; offset < total_elements; offset += elements_per_register) {
        uint32_t remaining = total_elements - offset;
        uint32_t count = remaining < elements_per_register ? remaining : elements_per_register;
        auto coord = asc::te::make_coord(offset);
        auto value = loader.load(src, coord);
        storer.store(dst, coord, value, count);
    }
    storer.flush(dst, static_cast<int32_t>(total_elements));
}
