store

产品支持情况​

  • Ascend 950PR&950DT系列产品：支持
  • Atlas A3系列产品：不支持
  • Atlas A2系列产品：不支持
  • Atlas 200I/500 A2推理产品：不支持
  • Atlas推理系列产品AI Core：不支持
  • Atlas推理系列产品Vector Core：不支持
  • Atlas训练系列产品：不支持

功能说明​

头文件路径为："tensor_api/experimental/arch/vector/reg_data_store.h"，命名空间为asc::te::experimental。

store用于将reg_tensor中的数据搬出到Unified Buffer（UB）Tensor。接口支持以下两类源寄存器：

  • 矢量数据寄存器搬出：通过store_sideband_mode选择正常搬出、首元素搬出、交织搬出或压缩搬出。
  • 掩码寄存器搬出：使用reg_tensor<bool>作为单源操作数，通过direct按原样搬出掩码比特，或通过pack隔位压缩搬出。两种模式均不读取src.mask。

接口支持以下两种寻址方式：

  • 传入coord时，从tensor.engine() + tensor.layout()(coord)对应的元素开始写入。
  • 不传入coord时，从tensor起始位置开始写入。

intlv模式使用双源操作数重载，其他模式使用单源操作数重载。

函数原型​

矢量数据寄存器搬出​

  • 单源操作数，指定坐标：

    C++
    template <store_sideband_mode sideband_mode = store_sideband_mode::direct,
          typename Tensor,
          typename Coord,
          typename RegDataType>
__simd_callee__ inline void store(
    Tensor& tensor,
    const Coord& coord,
    const reg_tensor<RegDataType>& src)

  • 单源操作数，从Tensor起始位置搬出：

    C++
    template <store_sideband_mode sideband_mode = store_sideband_mode::direct,
          typename Tensor,
          typename RegDataType>
__simd_callee__ inline void store(
    Tensor& tensor, const reg_tensor<RegDataType>& src)

  • 双源操作数，指定坐标：

    C++
    template <store_sideband_mode sideband_mode = store_sideband_mode::intlv,
          typename Tensor,
          typename Coord,
          typename RegDataType>
__simd_callee__ inline void store(
    Tensor& tensor,
    const Coord& coord,
    const reg_tensor<RegDataType>& src0,
    const reg_tensor<RegDataType>& src1)

  • 双源操作数，从Tensor起始位置搬出：

    C++
    template <store_sideband_mode sideband_mode = store_sideband_mode::intlv,
          typename Tensor,
          typename RegDataType>
__simd_callee__ inline void store(
    Tensor& tensor,
    const reg_tensor<RegDataType>& src0,
    const reg_tensor<RegDataType>& src1)

掩码寄存器搬出​

复用上述两个单源操作数原型，分别支持指定coord和从Tensor起始位置搬出。传入reg_tensor<bool>，由src推导出RegDataType为bool。不支持双源操作数原型。

参数说明​

矢量数据寄存器搬出​

表1 模板参数说明

参数名描述
sideband_mode搬出模式，类型为store_sideband_mode。单源操作数重载的默认值为store_sideband_mode::direct；双源操作数重载的默认值为store_sideband_mode::intlv。支持的模式请参考表3。
Tensor目的Tensor类型，由函数实参自动推导。Tensor必须位于UB。
Coord目的Tensor的坐标类型，由函数实参自动推导。
RegDataType源寄存器元素类型，由函数实参自动推导。与目的Tensor的元素类型一致，但目的Tensor的元素类型为int4b_t时，源寄存器的元素类型为int4x2_t。

表2 参数说明

参数名输入/输出描述
tensor输出目的Tensor，必须位于UB。
coord输入搬出起始元素在tensor逻辑布局中的坐标。
src输入单源操作数重载的源寄存器。direct、pack和pack_quarter使用src.mask筛选有效元素，store_1st忽略src.mask。
src0输入intlv模式的第一个源寄存器。该模式忽略src0.mask。
src1输入intlv模式的第二个源寄存器。该模式忽略src1.mask。

表3 矢量数据寄存器搬出模式

表中的VL表示一个矢量数据寄存器的长度，单位为Byte。int4b_t类型的数据在寄存器中以int4x2_t形式存储。int4x2_t数据类型由两个四位整型数打包为一个8比特存储单元，fp4x2_e2m1_t和fp4x2_e1m2_t数据类型由两个独立的四位浮点数打包为一个8比特存储单元，因此，对于这三种类型，下表所述的“元素”是指一个8比特对应的搬运单元，而不是单个4比特值。

取值含义搬出起始地址对齐约束（Byte）
store_sideband_mode::direct正常模式，根据src.mask将源寄存器中的有效元素连续写入UB中的对应位置。32
store_sideband_mode::store_1st仅将src的第一个元素写入UB，忽略src.mask。sizeof(RegDataType)
store_sideband_mode::intlv交织模式，将src0和src1中的元素交替写入UB，得到2*VL数据量，忽略两个源操作数的mask。仅支持双源操作数重载。32
store_sideband_mode::pack2倍压缩模式，根据src.mask筛选有效元素，将每个有效元素的低半部分bit写入压缩后的位置。min(32, VL/2)
store_sideband_mode::pack_quarter4倍压缩模式，根据src.mask筛选有效元素，将每个有效32bit元素的低8bit写入压缩后的位置。min(32, VL/4)

掩码寄存器搬出​

源寄存器元素类型为bool，目的Tensor的元素类型仅支持uint8_t、uint16_t和uint32_t。支持的模式请参考表6。

返回值说明​

两类搬出均无返回值。

约束说明​

  • 仅支持位于UB的Tensor。
  • 实际搬出起始地址必须满足表3或表6中的对齐约束。
  • 传入coord时，坐标维数必须与Tensor布局匹配，且坐标不能越界。
  • 单源操作数重载不支持store_sideband_mode::intlv；双源操作数重载仅支持store_sideband_mode::intlv。
  • 矢量数据寄存器搬出时，direct、pack和pack_quarter模式要求src.reg和src.mask均已初始化；store_1st和intlv模式仅要求参与搬出的reg成员已初始化。
  • 矢量数据寄存器以direct模式搬出时，如果目的UB的剩余空间不足一个VL，必须通过src.mask关闭越界位置，并保证目的UB至少剩余一个DataBlock（32B）空间。
  • 掩码寄存器搬出时，仅需初始化src.reg。目的Tensor的UB缓冲区必须能容纳表6所列的完整写入量，不能通过src.mask缩减写入范围。
  • 寄存器数据搬出应在__simd_vf__函数或__simd_callee__函数中完成。

调用示例​

正常搬出​

以下示例将源Tensor搬入寄存器，绑定全有效mask后写入目的Tensor。

C++
#include "tensor_api/tensor.h"
#include "tensor_api/experimental/arch/vector/mask_reg_compute.h"
#include "tensor_api/experimental/arch/vector/reg_data_load.h"
#include "tensor_api/experimental/arch/vector/reg_data_store.h"

template <typename T, typename SrcTensor, typename DstTensor>
__simd_vf__ inline void LoadAndStore(const SrcTensor& src, DstTensor& dst)
{
    auto coord = asc::te::make_coord(0);
    auto value = asc::te::experimental::load(src, coord);
    value.with_mask(asc::te::experimental::all_mask<T>());
    asc::te::experimental::store(dst, coord, value);
}

交织搬出​

C++
template <typename T, typename DstTensor>
__simd_vf__ inline void StoreInterleaved(
    DstTensor& dst,
    const asc::te::experimental::reg_tensor<T>& even,
    const asc::te::experimental::reg_tensor<T>& odd)
{
    asc::te::experimental::store<asc::te::experimental::store_sideband_mode::intlv>(
        dst, asc::te::make_coord(0), even, odd);
}

掩码寄存器搬出​

以下示例将同一个掩码分别搬出到两个UB Tensor。两个Tensor的元素类型均可为uint8_t、uint16_t或uint32_t。direct_dst须按32字节对齐且至少包含32字节，packed_dst须按16字节对齐且至少包含16字节。

C++
template <typename DirectTensor, typename PackedTensor>
__simd_vf__ inline void StoreMask(DirectTensor direct_dst, PackedTensor packed_dst)
{
    using namespace asc::te::experimental;
    auto mask = all_mask<uint16_t>();
    store(direct_dst, mask);
    store<store_sideband_mode::pack>(packed_dst, asc::te::make_coord(0), mask);
}
