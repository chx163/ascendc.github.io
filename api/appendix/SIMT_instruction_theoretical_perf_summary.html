SIMT指令理论性能汇总

本节汇总介绍了SIMT接口的理论性能，仅针对如下型号生效：

  • Ascend 950PR/Ascend 950DT

对本节提供的理论性能指标说明如下：

  • 理论并行度是指单个Vector Core在一个cycle内可以处理的理论最大元素数量。
  • 本节仅汇总由单一硬件指令实现的接口的理论性能，部分软仿接口或由多条硬件指令拼接实现的接口，则不提供理论性能。各接口的软仿情况请参考SIMT接口软仿情况汇总。
