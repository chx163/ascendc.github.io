其中：

  • asc_bfloat162e2m1x2_<round_mode>和asc_bfloat162e1m2x2_<round_mode>的源数据类型为bfloat16_t，<round_mode>可取：rd（FLOOR，向下取整）、rn（RINT，按RINT规则舍入）、rna（ROUND，舍入到最近整数）、ru（CEIL，向上取整）和rz（TRUNC，向零截断）。
  • asc_half2int4x2_<round_mode><sat_mode>、asc_half2int8_<round_mode><sat_mode>和asc_half2uint8_<round_mode><sat_mode>的源数据类型为half，<round_mode>可取：rd（FLOOR，向下取整）、rn（RINT，按RINT规则舍入）、rna（ROUND，舍入到最近整数）、ru（CEIL，向上取整）和rz（TRUNC，向零截断）。
  • asc_float2e5m2_rn<sat_mode>和asc_float2e4m3_rn<sat_mode>固定使用rn舍入。
  • asc_float2hif8_<round_mode><sat_mode>和asc_half2hif8_<round_mode><sat_mode>的<round_mode>可取rh（HIFLOAT8专用舍入模式）和rna（ROUND，舍入到最近整数）。
  • <sat_mode>可为空（非饱和）或取_sat（饱和）。asc_int162uint8、asc_int322uint8、asc_uint162uint8和asc_uint322uint8仅支持不带后缀和带_sat后缀两种形式，不支持<round_mode>。
